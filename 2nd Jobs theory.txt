# Fibonacci using Recursive and Non-Recursive Methods

Let's understand this practical from absolute zero, step by step. Don't worry if you are new to programming. We'll first understand what Fibonacci means, then understand the logic of both methods, and finally do a dry run with an example.

## 1. What is the Fibonacci series?

The Fibonacci series is a sequence of numbers in which each new number is the sum of the previous two numbers.

The series starts with 0 and 1.

# 0, 1, 1, 2, 3, 5, 8, 13, 21...

How each number is calculated:

0 + 1 = 1

1 + 1 = 2

1 + 2 = 3

2 + 3 = 5

For example:

- First number = 0
- Second number = 1
- Third number = 0 + 1 = 1
- Fourth number = 1 + 1 = 2
- Fifth number = 1 + 2 = 3

Important: In your program, `n` means the position of the Fibonacci number you want.

For example:

- `n = 0` gives 0
- `n = 1` gives 1
- `n = 5` gives 5

Your program calculates the Fibonacci number at position `n`, not the entire series.

## 2. What are Recursive and Non-Recursive methods?

There are two ways to solve this problem.

A. Recursive method

A function calls itself again and again to solve a smaller version of the same problem.

Example:

`fib(5)` calls `fib(4)` and `fib(3)`.

Uses function calls

B. Non-Recursive method (Iterative)

It uses a loop (`for` loop) to calculate the next number.

Example:

Start with `0, 1`, then keep adding them to get the next number.

Uses a loop

## 3. Recursive method — understand the code

First, let's look at the code with correct Python indentation.

```
steps = 0def fib_recursive(n):    global steps    steps += 1    if n <= 1:        return n    return fib_recursive(n-1) + fib_recursive(n-2)
```

Let's understand every line.

### Line 1: `steps = 0`

```
steps = 0
```

- We create a variable called `steps`.
- It starts from 0.
- It counts how many times the recursive function is called.

Think of it as a counter.

### Line 2: `def fib_recursive(n):`

```
def fib_recursive(n):
```

- `def` is used to create a function in Python.
- `fib_recursive` is the function name.
- `n` is the input given to the function.

For example, if we call:

```
fib_recursive(5)
```

Then the value of `n` is 5.

### Line 3: `global steps`

```
global steps
```

This is important.

Normally, a variable created inside a function is local to that function.

But we want to use the `steps` variable created outside the function.

So we write:

```
global steps
```

It tells Python:

"Use the same `steps` variable that was created outside this function."

### Line 4: `steps += 1`

```
steps += 1
```

This means:

```
steps = steps + 1
```

Every time the function runs, the counter increases by 1.

For example:

| Function call | Steps |
| ------------- | ----- |
| First call    | 1     |
| Second call   | 2     |
| Third call    | 3     |
| Fourth call   | 4     |

This helps us count the total number of recursive function calls.

### Line 5 and 6: The base condition

```
if n <= 1:    return n
```

This is called the base condition or base case.

It tells the function when to stop calling itself.

Remember:

- If `n = 0`, return 0.
- If `n = 1`, return 1.

Why do we need this?

Because if a function keeps calling itself without stopping, it will continue indefinitely until Python raises an error.

The base condition stops that process.

### Line 7: The main recursive logic

```
return fib_recursive(n-1) + fib_recursive(n-2)
```

This is the most important line.

It follows the Fibonacci formula:

\\[ F(n)=F(n-1)+F(n-2) \\]

In simple words:

Current Fibonacci number = Previous number + Number before previous.

For example, when `n = 5`:

```
fib_recursive(5)
```

It becomes:

```
fib_recursive(4) + fib_recursive(3)
```

And each of those calls breaks into smaller calls until it reaches 0 or 1.

### How recursion works visually

For `fib_recursive(5)`, the function calls look like this:

## Recursive call tree for n = 5

fib(5)

fib(4)

fib(3)

Each call splits into two smaller calls until it reaches 1 or 0.

For example, fib(4) calls fib(3) and fib(2). The same smaller calculations can happen more than once.

Let's calculate the result:

- `fib(0) = 0`
- `fib(1) = 1`
- `fib(2) = 1 + 0 = 1`
- `fib(3) = 1 + 1 = 2`
- `fib(4) = 2 + 1 = 3`
- `fib(5) = 3 + 2 = 5`

So the answer is 5.

## 4. Non-Recursive method — understand the code

Now let's understand the second method.

```
def fib_iterative(n):    a, b = 0, 1    count = 0    for i in range(n):        count += 1        a, b = b, a+b    return (0 if n == 0 else a), count
```

This method uses a `for` loop instead of calling the function again and again.

### Line 1: Function definition

```
def fib_iterative(n):
```

We create a function named `fib_iterative`.

It accepts `n` as input.

### Line 2: `a, b = 0, 1`

```
a, b = 0, 1
```

This is called multiple assignment.

It means:

```
a = 0b = 1
```

We use two variables to store the previous two Fibonacci numbers.

- `a` stores the first number.
- `b` stores the second number.

Initially:

# 0

a

# 1

b

### Line 3: `count = 0`

```
count = 0
```

This variable counts how many times the loop runs.

### Line 4: The for loop

```
for i in range(n):
```

This means the loop will run `n` times.

For example, if:

```
n = 5
```

Then:

```
range(5)
```

produces:

```
0, 1, 2, 3, 4
```

That means the loop runs 5 times.

### Line 5: `count += 1`

```
count += 1
```

Every time the loop runs, the count increases by 1.

If the loop runs 5 times, the final count is 5.

### Line 6: The most important line

```
a, b = b, a+b
```

This calculates the next Fibonacci number.

It means:

- New `a` becomes the old `b`.
- New `b` becomes the sum of old `a` and old `b`.

Python evaluates the right side first, so both new values are calculated using the old values.

For example, if:

```
a = 0b = 1
```

After this statement:

```
a = 1b = 1
```

The next time:

```
a = 1b = 2
```

And so on.

### Line 7: Return statement

```
return (0 if n == 0 else a), count
```

This returns two values:

1. The Fibonacci number.
2. The number of loop iterations.

The expression:

```
0 if n == 0 else a
```

means:

- If `n` is 0, return 0.
- Otherwise, return `a`.

Why is this needed?

Because when `n = 0`, the loop doesn't run at all. In that case, `a` is already 0, but this condition makes the special case explicit.

## 8. Time complexity — important for DAA viva

Time complexity tells us how the running work of an algorithm increases when the input size increases.

### Recursive method: O(2ⁿ)

Why?

Because every non-base recursive call makes two more calls:

```
fib_recursive(n-1) + fib_recursive(n-2)
```

So the number of calls grows very quickly as `n` increases.

### Non-Recursive method: O(n)

Why?

Because the `for` loop runs exactly `n` times.

If `n = 5`, it runs 5 times.

If `n = 100`, it runs 100 times.

The work increases in proportion to `n`.

This is the version I recommend writing in your practical exam.

```

jobs = [
    ("J1", 2, 100),
    ("J2", 1, 19),
    ("J3", 2, 27),
    ("J4", 1, 25),
    ("J5", 3, 15)
]

# Sort jobs by profit
jobs.sort(key=lambda x: x[2], reverse=True)

# Find maximum deadline
max_deadline = max(job[1] for job in jobs)

# Create empty slots
slots = [None] * max_deadline
total_profit = 0

# Schedule each job
for job in jobs:
    name, deadline, profit = job

    for j in range(deadline - 1, -1, -1):
        if slots[j] is None:
            slots[j] = name
            total_profit += profit
            break

print("Scheduled Jobs:", slots)
print("Total Profit:", total_profit)

```

# 6. Theory for practical examination

Aim: To implement Job Sequencing with Deadlines using the Greedy Method.

Theory: Job Sequencing is a scheduling problem in which jobs are selected based on their deadlines and profits. Each job requires one unit of time. The Greedy method selects jobs in descending order of profit and places each job in the latest available time slot before its deadline to maximize total profit.

Algorithm:

1. Start.
2. Create a list of jobs with their deadlines and profits.
3. Sort jobs in descending order of profit.
4. Find the maximum deadline.
5. Create empty time slots.
6. Select each job one by one.
7. Find the latest available slot before its deadline.
8. If a slot is available, schedule the job and add its profit.
9. Display scheduled jobs and total profit.
10. Stop.

Time Complexity: O(n²), where n is the number of jobs.

Space Complexity: O(n), for storing the time slots (excluding the input jobs).

Conclusion: Thus, Job Sequencing with Deadlines is successfully implemented using the Greedy Method to obtain maximum profit.

# Practical 3: Fractional Knapsack Using Greedy Method

Let's understand your code line by line in very simple language, assuming you are a beginner in Python.

## 1. First, understand the problem

In the Fractional Knapsack problem, we have:

- Items with different weights.
- Each item gives us some profit.
- A bag has a limited capacity.
- We want to get the maximum profit.

The important rule is: We can take a fraction (part) of an item if the full item does not fit.

For example, if an item weighs 30 kg but only 20 kg of space is left, we can take 20 kg of that item.

## 2. Your code explained line by line

### Step 1: Define profit, weight and capacity

```
profit = [60, 100, 120]
weight = [10, 20, 30]
capacity = 50
```

Here:

- `profit` stores the profit of each item.
- `weight` stores the weight of each item.
- `capacity` stores the maximum weight the bag can hold.

# Practical 4: 0/1 Knapsack Using Dynamic Programming

Let's understand your code step by step in very simple English, just like we learned Fractional Knapsack.

## 1. First, understand the problem

In the 0/1 Knapsack problem:

- We have some items.
- Every item has a weight and profit.
- Our bag has a limited capacity.
- We want to get maximum profit.

Important rule: We can either take the complete item (1) or leave it (0). We cannot take half of an item.

For example:

| Item   | Profit | Weight |
| ------ | ------ | ------ |
| Item 1 | 60     | 10     |
| Item 2 | 100    | 20     |
| Item 3 | 120    | 30     |

Bag capacity = 50 kg.

## 2. Understand the code line by line

### Step 1: Store profit, weight and capacity

```
profit = [60, 100, 120]
weight = [10, 20, 30]
capacity = 50
```

- `profit` stores the profit of each item.
- `weight` stores the weight of each item.
- `capacity` stores the maximum weight of the bag.

### Step 2: Count the number of items

```
n = len(profit)
```

`len()` counts the number of elements in the list.

There are 3 items.

Therefore:

```
n = 3
```

### Step 3: Create the DP table

```
dp = [
    [0 for x in range(capacity + 1)]
    for y in range(n + 1)
]
```

Most important line

First, understand what DP means.

DP = Dynamic Programming

It means solving a big problem by solving smaller problems and storing their answers.

Here, we create a table called `dp` to store the maximum profit for different numbers of items and different bag capacities.

Let's break the code into two parts.

Part A:

```
[0 for x in range(capacity + 1)]
```

- `capacity = 50`
- `range(capacity + 1)` means 0 to 50.
- We create 51 zeros.

Part B:

```
for y in range(n + 1)
```

- `n = 3`
- `range(n + 1)` means 0 to 3.
- We create 4 rows.

So our DP table has:

- 4 rows (0 to 3 items).
- 51 columns (0 to 50 kg capacity).

Every value is initially zero.

For understanding, here is a smaller example of the table structure:

| Items / Capacity | 0 | 1 | 2 | 3 | ... |
| ---------------- | - | - | - | - | --- |
| 0 items          | 0 | 0 | 0 | 0 | ... |
| 1 item           | 0 | 0 | 0 | 0 | ... |
| 2 items          | 0 | 0 | 0 | 0 | ... |
| 3 items          | 0 | 0 | 0 | 0 | ... |

Why do we use 0 initially?

Because if there are no items or the bag capacity is zero, the maximum profit is zero.

### Step 4: Start the outer loop

```
for i in range(1, n + 1):
```

This loop selects items one by one.

Since `n = 3`, it runs three times:

- First iteration: `i = 1`
- Second iteration: `i = 2`
- Third iteration: `i = 3`

### Step 5: Start the inner loop

```
for w in range(1, capacity + 1):
```

This loop checks different bag capacities from 1 to 50.

For example:

- `w = 1`: Bag capacity is 1 kg.
- `w = 2`: Bag capacity is 2 kg.
- `w = 3`: Bag capacity is 3 kg.
- ...
- `w = 50`: Bag capacity is 50 kg.

So the program checks different combinations of items and capacities.

### Step 6: Check whether the item fits

```
if weight[i - 1] <= w:
```

This condition checks whether the current item's weight is less than or equal to the current bag capacity.

Why `i - 1`?

Python list indexing starts from zero.

| Item number (`i`) | List index (`i-1`) |
| ----------------- | ------------------ |
| 1                 | 0                  |
| 2                 | 1                  |
| 3                 | 2                  |

For example, when `i = 1`:

```
weight[i - 1]
weight[0]
```

The weight is 10.

### Step 7: Calculate maximum profit

```
dp[i][w] = max(
    profit[i - 1] + dp[i - 1][w - weight[i - 1]],
    dp[i - 1][w]
)
```

Most important formula

This line compares two choices.

Choice 1: Include the current item

```
profit[i - 1] + dp[i - 1][w - weight[i - 1]]
```

It means:

- Take the profit of the current item.
- Add the maximum profit possible with the remaining capacity.

Choice 2: Exclude the current item

```
dp[i - 1][w]
```

It means:

- Do not take the current item.
- Keep the maximum profit calculated without it.

What does `max()` do?

It selects whichever choice gives more profit.

In simple words:

\\[ DP[i][w] = \max(\text{Include},\text{Exclude}) \\]

### Step 8: If the item does not fit

```
else:
    dp[i][w] = dp[i - 1][w]
```

If the item's weight is greater than the bag capacity, we cannot take it.

Therefore, we simply copy the previous maximum profit.

### Step 9: Print the answer

```
print("Maximum Profit:", dp[n][capacity])
```

Here:

- `n = 3`
- `capacity = 50`

Therefore:

```
dp[3][50]
```

This gives the maximum profit using all 3 items with a bag capacity of 50.

The 8 Queens problem is a problem of placing 8 queens on an 8×8 chessboard so that no two queens attack each other. Backtracking is used to find a valid arrangement.
