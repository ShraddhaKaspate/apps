## 2. What is Uber Fare Prediction?

Uber Fare Prediction is a Machine Learning technique used to estimate the taxi fare based on journey details.

For example, when a person books an Uber, the fare may depend on:

- Pickup location
- Drop-off location
- Number of passengers
- Distance and journey details

The model learns from previous Uber trip data and predicts the fare for a new trip.

Example:

| Pickup     | Drop-off   | Passengers | Fare |
| ---------- | ---------- | ---------- | ---- |
| Location A | Location B | 2          | ₹150 |
| Location C | Location D | 1          | ₹250 |
| Location E | Location F | 3          | ₹350 |

These are illustrative examples.

### Step 4: Calculate Q1

```

```

Explanation:

- `fare_amount` is the column containing Uber fare values.
- `quantile(0.25)` calculates the first quartile (Q1).
- Q1 represents the 25th percentile of the fare data.

### Step 5: Calculate Q3

```

```

Explanation:

- `quantile(0.75)` calculates the third quartile (Q3).
- Q3 represents the 75th percentile.

Approximately 75% of fare values are below Q3.

### Step 6: Calculate IQR

```
IQR = Q3 - Q1
```

Explanation:

- IQR stands for Interquartile Range.
- It measures the spread of the middle 50% of the data.

Formula:

\\[ IQR = Q3-Q1 \\]

Example:

If Q1 = 100 and Q3 = 300:

\\[ IQR = 300-100=200 \\]

### Step 7: Remove Outliers

```
df = df[    df["fare_amount"].between(        Q1 - 1.5 * IQR,        Q3 + 1.5 * IQR    )]
```

This is an important step.

What are outliers?

Outliers are values that are unusually high or low compared to the other values in a dataset.

For example:

```
100, 150, 200, 250, 300, 5000
```

Here, 5000 may be an outlier.

Explanation of the code:

- `between()` checks whether fare values fall within a specified range.
- `Q1 - 1.5 * IQR` calculates the lower limit.
- `Q3 + 1.5 * IQR` calculates the upper limit.
- Values outside these limits are removed.

Formula:

\\[ Lower=Q1-1.5(IQR) \\]

\\[ Upper=Q3+1.5(IQR) \\]

Why remove outliers?

Because extremely unusual values can affect the performance of the prediction model.

Explanation:

- `r2_score()` evaluates the performance of the regression model.
- `y_test` contains actual fare values.

What is R² Score?

R² stands for Coefficient of Determination.

It tells us how well the model explains the variation in the actual fare values.

| R² Value | Meaning                                 |
| -------- | --------------------------------------- |
| 1        | Perfect prediction                      |
| 0        | No improvement over predicting the mean |
| Negative | Worse than predicting the mean          |

Generally, a higher R² score indicates better performance.

### Step 20: Calculate RMSE

```
print(    "RMSE:",    mean_squared_error(y_test, linear_predictions) ** 0.5)
```

Explanation:

- `mean_squared_error()` calculates Mean Squared Error (MSE).
- `** 0.5` takes the square root of MSE.
- This gives RMSE.
- RMSE measures the average size of prediction errors in the same units as the fare.

Formula:

\\[ RMSE=\sqrt{\frac{\sum(y-\hat y)^2}{n}} \\]

Where:

- \\(y\\) = Actual fare
- \\(\hat y\\) = Predicted fare
- \\(n\\) = Total number of predictions

Example:

If RMSE = 20, the model's prediction errors have a typical magnitude of around 20 fare units.

A lower RMSE generally means better predictions.

| Linear Regression              | Random Forest Regression           |
| ------------------------------ | ---------------------------------- |
| Uses a linear relationship     | Uses multiple decision trees       |
| Simple algorithm               | More complex algorithm             |
| Creates a best-fit line        | Combines multiple tree predictions |
| Works well for linear patterns | Can capture complex patterns       |
| Usually faster to train        | Can require more computation       |

## 1. Aim of the Practical

## 2. What is Email Spam Detection?

Email spam detection is a machine learning technique used to classify emails into two categories:

- Spam (1): Unwanted or fake emails, such as advertisements and fraudulent messages.
- Not Spam (0): Genuine emails, such as personal and professional messages.

For example:

| Email                          | Prediction   |
| ------------------------------ | ------------ |
| You won a lottery! Click here  | Spam (1)     |
| Your college exam timetable    | Not Spam (0) |
| Claim your free prize now      | Spam (1)     |
| Meeting scheduled for tomorrow | Not Spam (0) |

The machine learning model learns from previous email data and predicts whether a new email is spam or not.

# Theory: Email Spam Detection Using KNN and SVM

## 1. Introduction

Email spam detection is a technique used to identify unwanted or fraudulent emails. Spam emails generally contain advertisements, fake offers, suspicious links, or misleading information.

Machine Learning helps computers identify spam emails automatically by learning patterns from previously available email data.

In this practical, we use two supervised machine learning classification algorithms:

1. K-Nearest Neighbors (KNN)
2. Support Vector Machine (SVM)

Both algorithms classify emails into two categories:

- Spam (1): Unwanted emails.
- Not Spam (0): Genuine emails.

## 2. What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence (AI) that allows computers to learn from data and make predictions or decisions without being explicitly programmed for every task.

In this practical, the machine learns from existing email data and predicts whether an email is spam or not spam.

## 3. What is Classification?

Classification is a supervised machine learning technique used to divide data into predefined categories or classes.

For example, in email spam detection, the two classes are:

- Class 0 – Not Spam
- Class 1 – Spam

The model learns from labelled training data and predicts the category of new data.

## 4. K-Nearest Neighbors (KNN) Algorithm

KNN is a supervised machine learning algorithm used for classification and regression.

It classifies new data based on the nearest data points available in the training dataset.

Working of KNN:

1. Select the value of K (number of neighbors).
2. Calculate the distance between the new data point and existing data points.
3. Find the K nearest neighbors.
4. Check the majority class among those neighbors.
5. Assign the majority class to the new data point.

In this practical, we use `n_neighbors=5`, which means the algorithm considers five nearest neighbors to classify an email.

Advantages:

- Easy to understand and implement.
- Simple algorithm.
- No complex training process.

Disadvantages:

- Slow for large datasets.
- Performance depends on the value of K.
- Sensitive to irrelevant features and feature scaling.

## 5. Support Vector Machine (SVM) Algorithm

SVM is a supervised machine learning algorithm mainly used for classification.

It works by finding the best decision boundary, called a hyperplane, to separate different classes of data.

In email spam detection, SVM separates spam emails from genuine emails based on their features.

Working of SVM:

1. Takes the training data as input.
2. Identifies different classes of data.
3. Finds the best separating hyperplane.
4. Maximizes the margin between the classes.
5. Uses the learned boundary to classify new emails.

Advantages:

- Effective for high-dimensional datasets.
- Works well for classification problems.
- Can handle complex decision boundaries using kernels.

Disadvantages:

- Can be slow on large datasets.
- Choosing the right kernel and parameters can be difficult.
- Requires feature scaling for better performance.

## 6. Training and Testing Data

In machine learning, the dataset is divided into two parts:

Training Data: Used to train the model and help it learn patterns.

Testing Data: Used to evaluate the performance of the trained model on unseen data.

In this practical:

- 80% data is used for training.
- 20% data is used for testing.

## 7. Model Evaluation

After training the models, we evaluate their performance using the following methods.

A. Accuracy

Accuracy measures the percentage of correctly classified emails.

\\[ Accuracy = \frac{Correct\ Predictions}{Total\ Predictions}\times100 \\]

B. Confusion Matrix

A confusion matrix is a table used to evaluate the performance of a classification model.

It contains four values:

| Term                | Meaning                                   |
| ------------------- | ----------------------------------------- |
| True Positive (TP)  | Spam correctly identified as Spam         |
| True Negative (TN)  | Not Spam correctly identified as Not Spam |
| False Positive (FP) | Not Spam incorrectly identified as Spam   |
| False Negative (FN) | Spam incorrectly identified as Not Spam   |

1. Gmail and other email filtering systems.
2. Detection of phishing emails.

4. Protection against fraudulent messages.
5. Improving email security.

Q1. What is the aim of this practical?

To perform clustering on sales data using the K-Means algorithm and find the optimal number of clusters using the Elbow Method.

Q2. What is clustering?

Clustering is a machine learning technique used to divide similar data points into groups.

Q3. What is K-Means?

K-Means is an unsupervised machine learning algorithm used to divide data into K clusters.

Unsupervised learning.

Q5. What is a centroid?

A centroid is the center point of a cluster.

Q6. What is the Elbow Method?

It is a technique used to find the optimal number of clusters by plotting WCSS against the number of clusters.

Q7. What is WCSS?

WCSS stands for Within-Cluster Sum of Squares. It measures the sum of squared distances between data points and their assigned cluster centers.

Q8. What is StandardScaler?

StandardScaler is used to standardize numerical data so that features have approximately zero mean and unit standard deviation.

Q9. Why is scaling required in K-Means?

Because K-Means uses distance calculations, features with larger numerical ranges can dominate the clustering process.

It means the algorithm divides the data into three clusters.

Q11. What does `random_state=42` do?

It makes the random initialization reproducible.

Q12. What does `n_init=10` mean?

It runs K-Means 10 times with different initial centroid positions and selects the best result based on inertia.

Q13. What does `inertia_` represent?

It represents the WCSS value of the trained K-Means model.

Q14. What is `fit_predict()`?

It trains the model and assigns cluster labels to the data points.

Q15. What is the use of `set()`?

It removes duplicate values and gives unique cluster labels.

It counts the number of elements.
